# Hack Day 2026 - Open Source Booth Directory

Official mobile-first Open Source Booth Directory website for **Hack Day 2026**, organized by the **Developers Club** at **Newton School of Technology x Ajeenkya D Y Patil University (NST x ADYPU), Pune** in partnership with **Major League Hacking (MLH)**.

## Event Overview
- **Event**: Hack Day 2026
- **Organizer**: Developers Club at NST x ADYPU
- **Partners**: Major League Hacking (MLH), Newton School of Technology, Ajeenkya D Y Patil University
- **Booth Timings**: 11:00 AM – 4:00 PM, Saturday, 24 October 2026
- **Overnight Hackathon**: 4:00 PM 24 Oct – 4:00 AM 25 Oct (12 Hours)
- **Venue**: 4th Floor, Room 404, Newton School of Technology, ADYPU Campus, Lohegaon, Pune, Maharashtra 412105, India

## Tech Stack
- **React 19** with **Vite**
- **Tailwind CSS v4** (with neo-brutalist utilities)
- **React Router v7**
- **Lucide React**
- **Logos**: `mlh.png`, `devClub.png`, `nstLogo.png`, `adypuLogo.png`, and official organization PNGs

## Featured Open Source Booths
1. **OpenMRS**
2. **Oppia**
3. **Kubernetes**
4. **JSON Schema**
5. **Eventyay by FOSSASIA**

## Running Locally
```bash
# Install dependencies
pnpm install

# Start development server
pnpm run dev

# Build for production
pnpm run build
```
